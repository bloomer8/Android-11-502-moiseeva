Домашнее задание №3 — Notifications & Permissions

Проект: Kotlin + Jetpack Compose
Package: com.example.notificationspermissions
minSdk: 24
compileSdk/targetSdk: 36

Как открыть:
1. Распакуйте архив.
2. В Android Studio выберите File -> Open и укажите папку NotificationsPermissions.
3. Дождитесь Gradle Sync.
4. Запустите приложение на устройстве или эмуляторе Android 13+.

Реализовано:
- Запрос POST_NOTIFICATIONS на Android 13+.
- Экран-предупреждение и переход в настройки приложения при отказе.
- Заголовок и текст уведомления, BigTextStyle для длинного текста.
- Несмахиваемое уведомление по Checkbox.
- Важность MIN / DEFAULT / HIGH через отдельные Notification Channels.
- Открытие приложения по нажатию на уведомление и Toast с текстом/заголовком.
- Второй экран с запросом ACCESS_FINE_LOCATION и получением координат.
- Просмотр активных ID, редактирование и удаление всех активных уведомлений.

Важно:
- На Android 8+ важность канала фиксируется при первом создании. В проекте используются три отдельных канала, чтобы можно было выбирать MIN, DEFAULT и HIGH.
- Чтобы проверить редактирование/удаление, сначала отправьте несколько уведомлений, затем нажмите «Обновить список ID».
- Для определения координат включите геолокацию на устройстве. В эмуляторе задайте координаты в Extended Controls -> Location.
- Для сборки нужен установленный Android SDK 36 и JDK 17 (обычно Android Studio настраивает это автоматически).
